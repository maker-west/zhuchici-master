# 主持词大师 · WorkBuddy Skill

把一次活动的流程，变成主持人拿起来就能念的稿子。

这是一个 [WorkBuddy](https://www.workbuddy.cn) 的 Agent Skill（也适用于其他兼容 `SKILL.md` 规范的 Agent）。装上之后，直接对 Agent 说"帮我写一场表彰大会的主持词"即可调用。

---

## 它能做什么

- 覆盖 **3 大类 20 个场景**：政务仪式类（表彰大会、动员大会、开工揭牌、签约仪式、退休欢送、党建主题党日）、节庆晚会类（国庆 / 中秋 / 元旦 / 教师节 / 春节团拜 / 军民联欢 / 文化节开幕式）、人生礼仪类（婚礼、寿宴、升学宴、满月百日、同学聚会、追思告别）
- 每个场景内置**环节骨架 + 候选调性 + 撰稿要点**，不用从零编流程
- 格式对齐真实播出稿：说话人标记、环节编号、节目名《》+ 表演者独立成行、舞台提示【】单独成行
- 技法库：开场轮番排比、串场三明治、嘉宾报幕、政务名单三层分批宣读、商业口播、分会场连线、倒计时、结束语
- **强制不虚构**：不生成任何你没提供的人名、职务、单位、奖项、数据，一律留占位符并列入待补清单

## 不适合什么

演讲稿、领导讲话稿、致辞稿（那是讲话人自己的稿，不是主持人串场稿）。

## 安装

### 方式一：git clone（推荐，方便后续更新）

```bash
git clone https://github.com/maker-west/zhuchici-master.git ~/.workbuddy/skills/zhuchici-master
```

### 方式二：下载 zip

1. 打开仓库页面 → **Code** → **Download ZIP**
2. 解压，把文件夹放进 `~/.workbuddy/skills/`
3. 文件夹重命名成你喜欢的名字即可（例如 `zhuchici-master`）；skill 的真实名称取自 `SKILL.md` 顶部的 `name` 字段，与目录名无关

> 重启或重新索引后（约数秒）即可生效。WorkBuddy 会自动重新扫描 skills 目录。

### 更新

```bash
cd ~/.workbuddy/skills/zhuchici-master && git pull
```

## 怎么用

装上后直接用大白话触发，不需要记命令：

| 你说 | 它做 |
|---|---|
| 帮我写一场年度表彰大会的主持词 | 走政务仪式类骨架，先确认环节流程再动笔 |
| 我们有个开工奠基仪式，写个主持词，15 分钟 | 按 220 字/分钟控制篇幅 |
| 把这份流程单扩写成可播读的稿子 | 按你给的流程逐环节扩写 |
| 写国庆晚会开场，四个主持人 | 用晚会轮番排比开场 + 说话人标记 |

**政务类活动请务必人工核对**：领导姓名、职务排序、奖项名称、数据、民族宗教与台港澳表述，以主办方口径和上级文件为准。

## 目录结构

```
.
├── SKILL.md                        # 主文件：铁律、工作流、交付底线
└── references/
    ├── scene-library.md            # 3 大类 20 场景的环节骨架 + 调性（撰稿前必读）
    ├── output-format.md            # 真实播出稿格式规范 + 篇幅经验值
    ├── craft-patterns.md           # 撰稿技法库
    └── quality-checklist.md        # 出稿后自检清单
```

`references/` 采用渐进式加载：Agent 只在需要时才读取，不占用常驻上下文。

---

## 设计原则

1. 严禁虚构人名、职务、单位、奖项、数据
2. 名单照抄，不按职务高低重排
3. 政务表述零改写，拿不准就留占位
4. 播读词与舞台提示严格分家（非播读内容一律【】单独成行）
5. 每段话必须承担推进流程 / 交代规则 / 营造情绪 / 完成过渡中的一项
