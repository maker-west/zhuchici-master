# 出稿自检清单

写完逐条过，任何一条不过就改完再交付。

## 安全（硬性）

- [ ] 全文没有出现任何用户未提供的人名、职务、单位、奖项名称、文件号、数据、金额、日期
- [ ] 领导与嘉宾名单严格按用户给的原始顺序与职务原文引用，未重排、未"优化"、未补全
- [ ] 政务表述、民族宗教、台港澳表述、领导人论述与会议文件名称，只用了主办方原文
- [ ] 所有需要现场宣读的名单 / 品牌 / 奖品 / 数据都写成占位提示，且文末集中列出待补清单
- [ ] 嘉宾、致辞人、传讲人**未提供的发言内容**没有被代为撰写（只写通用承接）

## 格式（对齐真实播出稿）

- [ ] 舞台提示一律用【】单独成行，未混进播读词
- [ ] 说话人标记统一：首次全名、后续单字简称、多人齐说用 `合：`
- [ ] 环节有编号，节目名用《》，`表演者：` / `致辞（X 分钟）` 独立成行
- [ ] 每个节目前后都标了谁上场、谁接话
- [ ] 主持人简称在全文唯一可辨，无歧义

## 完整性

- [ ] 用户确认的每个环节都有对应段落，无遗漏
- [ ] 开场称谓、环节间串场衔接、结束语**完整写出**，无省略号糊弄
- [ ] 每个串场都走了三明治：回评上一节目 → 过渡 → 报幕
- [ ] 每个环节都有明确功能（推进流程 / 交代规则 / 营造情绪 / 完成过渡）

## 质量

- [ ] 语言贴合选定调性（政务书面规范 / 晚会调度感与画面感 / 礼仪情感真实）
- [ ] 无空洞套话、空泛排比、无信息量的形容；赞美落到具体细节
- [ ] 播读词按口语节奏断句，朗读不拗口（默读一遍验证）
- [ ] 篇幅按 220 字/分钟核算，与预计时长偏差不超过 20%

## 交付

- [ ] 文件名为 `{活动名}_主持词_{日期}.md`
- [ ] 文末附「待补充信息」清单 + 人工审校提醒
- [ ] 已用 present_files 打开预览
