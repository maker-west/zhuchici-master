# 场景库：3 大类 18 场景

每个场景 = **环节骨架**（该场景专业流程的默认顺序）+ **候选调性**（第一个为默认）+ **撰稿要点**。

使用方式：匹配场景 → 取骨架 → 按用户实际流程增删 → 选调性 → 逐环节写稿（格式见 `output-format.md`，技法见 `craft-patterns.md`，舞台提示统一用【】）。

第 19、20 两个场景直接提炼自真实播出稿（省级文化节开幕式、总台春晚级晚会），可信度最高，写同类大稿时优先参照。

---

## 一、政务单位

### 1. 表彰大会
- **骨架**：开场白 → 介绍到场领导与嘉宾 → 宣布会议开始、奏唱国歌 → 宣读表彰决定 → 分批组织颁奖并宣读名单 → 获奖代表发言 → 主要领导讲话 → 结束语
- **调性**：庄重规范 / 振奋提气 / 简练务实
- **要点**：颁奖分批时，每批都要写清"请 XX 上台领奖"的引导语和上下台动线提示；名单位置一律留占位符。

### 2. 动员大会
- **骨架**：开场白 → 介绍领导 → 说明会议背景与目的 → 宣读实施方案 / 部署任务 → 各单位表态发言 → 领导动员讲话 → 结束语与工作要求
- **调性**：庄重规范 / 振奋提气 / 简练务实
- **要点**：表态发言环节要写清发言顺序与时长控制；结束语落到实处的工作要求，别只喊口号。

### 3. 开工 · 揭牌仪式
- **骨架**：开场白 → 介绍到场领导与嘉宾 → 主办致辞 → 领导讲话 → 揭牌 / 培土环节 → 合影 → 结束语
- **调性**：庄重规范 / 喜庆热烈 / 简练务实
- **要点**：揭牌、培土是强执行环节，舞台提示要精确到站位、揭幕动作、礼花时点；户外仪式提示音响与天气备用语。

### 4. 签约仪式
- **骨架**：开场白 → 介绍双方到场人员 → 主办致辞 → 项目介绍 → 签约轮换笔仪式 → 交换文本 → 合影 → 结束语
- **调性**：庄重规范 / 大气正式 / 简练务实
- **要点**："轮换笔"是多轮签约的调度难点，提示写清第几轮、哪几家、上台顺序；交换文本后要提示面向镜头。

### 5. 荣誉退休欢送会
- **骨架**：开场白 → 介绍到场人员 → 介绍退休同志履历与贡献 → 敬献鲜花 / 纪念品 → 同事代表发言 → 本人感言 → 领导讲话 → 合影 → 结束语
- **调性**：温情真挚 / 庄重规范 / 轻松欢快
- **要点**：履历与贡献必须来自用户提供的材料，不得润色拔高；本人感言环节留弹性提示（可能超预期时长）。

### 6. 党建活动 · 主题党日
- **骨架**：开场白 → 说明活动主题 → 奏唱国歌 / 重温入党誓词 → 学习环节 → 交流发言 → 书记总结讲话 → 结束语
- **调性**：庄重规范 / 真挚朴实 / 简练务实
- **要点**：誓词、国歌等环节只写主持口令，不代写誓词正文；学习环节引用文件只写"（学习 XX 文件）"占位。

## 二、节庆晚会

### 7. 国庆文艺晚会
- **骨架**：开场白 → 介绍到场领导与嘉宾 → 致辞环节 → 节目串场（逐档衔接） → 互动抽奖 → 大合唱压台 → 结束语
- **调性**：恢弘大气 / 喜庆热烈 / 温情真挚
- **要点**：串场词要对得上具体节目名；节目名未知时写「（节目名称）」占位，绝不编节目。大合唱前要有起立、指挥上场的提示。

### 8. 中秋晚会
- **骨架**：开场白 → 介绍到场人员 → 领导致辞 → 节目串场 → 赏月互动 / 家书环节 → 结束语
- **调性**：温情真挚 / 诗意雅致 / 轻松欢快
- **要点**：家书、连线环节容易超时，需提示控制时长；诗意不等于堆砌古诗词，点到为止。

### 9. 元旦联欢晚会
- **骨架**：开场白 → 介绍到场人员 → 新年致辞 → 节目串场 → 游戏互动与抽奖 → 倒计时环节 → 结束语
- **调性**：喜庆热烈 / 轻松欢快 / 恢弘大气
- **要点**：倒计时是全场的调度高点，提示写清倒计时口令、主持人与全场互动方式、零点后的第一句话。

### 10. 教师节表彰 · 晚会
- **骨架**：开场白 → 介绍到场领导 → 致辞 → 宣读表彰名单并颁奖 → 学生献词 / 教师代表发言 → 节目串场 → 结束语
- **调性**：温情真挚 / 庄重规范 / 真挚朴实
- **要点**：表彰名单留占位；学生献词环节提示话筒高度、上下台引导。

### 11. 春节团拜 · 团拜会
- **骨架**：开场白 → 介绍到场领导与嘉宾 → 团拜致辞 → 节目串场 → 抽奖互动 → 集体敬酒 → 结束语
- **调性**：喜庆热烈 / 恢弘大气 / 温情真挚
- **要点**：敬酒环节要写清祝酒词与举杯时机提示；团拜会多桌次，提示走位与话筒覆盖。

### 12. 军民联欢活动
- **骨架**：开场白 → 介绍到场部队与地方领导 → 双方致辞 → 节目串场 → 拥军互动环节 → 合影 → 结束语
- **调性**：恢弘大气 / 庄重规范 / 喜庆热烈
- **要点**：部队领导称谓、职务以用户提供的原文为准，绝不按地方习惯改写；双方致辞顺序按用户给定顺序。

## 三、人生礼仪

### 13. 婚礼庆典
- **骨架**：开场白 → 新人入场 → 证婚 / 主婚 → 家长致辞 → 交换戒指 → 敬感恩茶 → 交杯酒与举杯 → 礼成送客 → 结束语
- **调性**：温情真挚 / 喜庆热烈 / 轻松欢快
- **要点**：新人、父母姓名一律留占位；敬茶环节的称谓（改口）极敏感，写成占位提示让主办方确认。

### 14. 寿宴 · 生日宴
- **骨架**：开场白 → 介绍寿星生平 → 晚辈代表祝词 → 子女致辞 → 上寿礼 / 切蛋糕 → 全家合影 → 结束语
- **调性**：温情真挚 / 喜庆热烈 / 诗意雅致
- **要点**：生平介绍只用主办方给的素材；年龄表述注意"逢十做大寿"等习俗差异，不确定就留白。

### 15. 升学宴 · 谢师宴
- **骨架**：开场白 → 介绍到场老师与亲友 → 学生及家长致辞 → 敬师环节 → 举杯答谢 → 结束语
- **调性**：温情真挚 / 喜庆热烈 / 简练务实
- **要点**：录取院校、专业名称由用户提供，不得臆测排序；谢师环节老师名单留占位。

### 16. 满月 · 百日宴
- **骨架**：开场白 → 介绍到场亲友 → 长辈致辞 → 呈长寿面 / 分喜蛋 → 合影 → 结束语
- **调性**：轻松欢快 / 温情真挚 / 喜庆热烈
- **要点**：婴儿姓名、生辰留占位；时长普遍偏短，稿子要精炼，别写成大晚会体量。

### 17. 同学聚会
- **骨架**：开场白 → 点名与追忆 → 师生致辞 → 自由发言与才艺 → 合影 → 结束语
- **调性**：轻松欢快 / 温情真挚 / 幽默风趣
- **要点**：点名涉及真实姓名，一律留占位符；幽默分寸要克制，避免涉及他人近况的玩笑。

### 18. 追思 · 告别仪式
- **骨架**：开场白 → 介绍生平 → 默哀 → 家属致答谢词 → 生前好友代表发言 → 告别行礼 → 结束语
- **调性**：肃穆庄重 / 真挚朴实 / 温情克制
- **要点**：全程不出现任何喜庆色彩词汇；生平只用家属确认的原文；默哀时长、行礼方式按主办方习俗，写成占位提示确认。

### 19. 文化节 / 旅游节开幕式（政务类扩展，源自真实省级开幕式稿）
- **骨架**：播放片头 → 开场表演（音乐秀 / 融合秀） → 主持人开场词（自报家门 + 活动定位） → 介绍到场嘉宾与领导（分三层：重要外宾 / 重要领导 / 其余打包） → 移交主持（"有请 XX 主持开幕式"） → 领导致辞（按人列时长） → 主要领导宣布开幕 → 主题曲 → 文艺表演分篇章（每篇章：主持人串场 → 文化传讲 / 节目 → 承接过渡） → 主持人结尾词（邀请语 + 升华 + 合：再见）
- **调性**：庄重规范 / 恢弘大气 / 诗意雅致
- **要点**：
  - 名单排序、职务、称谓**照抄主办方名单**，分三层宣读（见技法库第 5 条）。
  - 篇章用「四字主题 + 副题」命名，每篇章配一位"文化传讲人 / 讲述者"，主持人只做引入与承接。
  - 致辞人的职务、姓名、时长单独列行，主持人只说"有请……致辞"。
  - 结尾用邀请语（诚邀您来 XX）+ 祝愿收束。

### 20. 大型综艺晚会（春晚级，含分会场，源自总台春晚主持词）
- **骨架**：开场轮番排比 + 合诵拜年 → 直播平台 / 传播口径播报 → 节目串场（含嘉宾报幕、人物访谈） → 商业口播段（每 3–5 个节目一次） → 分会场连线 → 特别来宾介绍 → 零点倒计时（跨年类） → 压轴节目 + 结尾升华 + 合：再见
- **调性**：恢弘大气 / 喜庆热烈 / 温情真挚
- **要点**：
  - 全场 30 个以上环节，串场每段 100–300 字，短句为主。
  - 大量使用"双人抖包袱 + 合诵报幕"，避免单人长篇抒情。
  - 设 3–5 位"特殊报幕人"（先进人物、行业代表、冠军），由主持人铺垫后交其报幕（见技法库第 4 条）。
  - 口播、抽奖、分会场连线分散在不同环节，避免集中。
  - 整体篇幅 10000–15000 字（4 小时量级）。
