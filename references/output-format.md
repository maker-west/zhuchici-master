# 输出格式规范（对齐真实播出稿）

规范取自两篇真实播出稿：总台春晚级节庆晚会主持词、省级文化节开幕式文字稿。目标是产出**导演组和主持人拿到就能直接排练**的稿子，不是文学草稿。

> 示例中的 A / B / C 代表主持人，实际出稿时替换为真实姓名。

## 一、舞台 / 执行提示用【】，不用 <>（重要）

真实播出稿一律用**方头括号【】**标注非播读内容，放在单独一行：

```
【嘉宾落座，9:00 准时开始】
【随着音乐四位主持人登场，大屏幕关上】
【舞蹈结束后，主持人 B 上台】
【XX 老师上场，主持人接一下】
【开幕结束后，主持人 B 上场】
```

要点：
- 提示写在**它发生的那个位置**（节目结束处、人物上场处），不要堆在段尾。
- 标注清楚**谁上场**：`【歌曲《XX》结束后，主持人 A、B 上台，开启篇章三】`。
- 时间、cue 点、屏幕开关、道具都写进去：`【手中拿出一本书】`、`【大屏幕关上】`。
- 播读词里绝不混入提示，两者严格分家。

## 二、说话人标记

- 首次出现用**全名**：`周某某：`；之后用**单字简称**：`周：`。简称取姓或名首字，**同一份稿里必须唯一可辨**（同姓则改用名或全名）。
- 多人齐说用 `合：`（用于拜年、报幕、倒计时、口号）。
- 嘉宾 / 特殊报幕人用自己的名字：`（特邀专家）：`、`（世界冠军代表）：`。
- 一人说多段时，换段续行不重复标记；**换人说话才换行标新说话人**。

## 三、环节用编号组织，节目信息独立成行

```
1.播放片头
2.融合音乐秀《和鸣迎宾曲》（地点：主舞台）
3. 主持人开场词
...
（一）篇章一：天人合一·"坊"见武当
...
12. 歌曲《天下太极出武当》；表演者：XXX、XXX
```

- 节目名一律用《》；`表演者：`、`文化传讲人：`、`致辞（5 分钟）` 单独成行，便于导演组拆单。
- 大环节用 `一、二、三` 或 `（一）（二）`，子环节用阿拉伯数字编号。
- 篇章标题用「四字主题 + 副题」对仗式：`天人合一·"坊"见武当`、`上善若水·润泽万物`、`和合共生·世界大同`。

## 四、交付文件结构

```markdown
# {活动名称} 主持词
（调性：XX　|　预计时长：XX 分钟　|　主持人：A、B、C）

【开场前提示：嘉宾落座，XX:XX 准时开始】

## 一、开场

1.播放片头
【音乐起，主持人登场，大屏幕上/关】

周某某：……
王某某：……
合：……

2.节目《XX》
表演者：……

## 二、……

## 结束语

周某某：……
合：朋友们，再见！

> 待补充信息：……
> 审校提醒：……
```

## 五、篇幅经验值（按 220 字/分钟播读速度估算）

| 活动体量 | 主持词篇幅 | 说明 |
|---|---|---|
| 30 分钟开幕式 | 4000–7000 字 | 主持串词 + 名单宣读占大头 |
| 90 分钟晚会 | 8000–12000 字 | 含商业口播与分会场连线 |
| 4 小时春晚级晚会 | 10000–15000 字 | 约 30–36 个环节，单段串场 2–4 句 |

致辞、传讲、演唱等环节**不占主持词篇幅**，按时长单独列（如 `致辞（5 分钟）`）。串场不是越长越好：一个节目前后的串场通常 100–300 字。
