# 撰稿技法库（从真实播出稿提炼）

以下技法全部对照总台春晚级晚会主持词、省级文化节开幕式文字稿归纳。出稿时按活动体量取用，不必全上。

## 1. 开场白

**节庆晚会——轮番排比 + 合诵收口**
主持人每人一句同构短句（同一句式、不同内容），最后合诵一句拜年/问候：

```
A：过年啦，带着满满的期盼！
B：拜年啦，送上满满的祝福！
C：到家啦，放下重重的行囊！
A：这里是中央广播电视总台《XX 晚会》的直播现场……
B：迎接……
C：迎接……
合：我们在这里给大家——拜年啦！
```

要点：单人句 8–15 字，节奏一致；合诵句是全场第一个情绪高点。

**政务 / 开幕式——自报家门 + 定位 + 介绍嘉宾**

```
A：尊敬的各位来宾，亲爱的海内外朋友们，大家上午好！
合：上午好！
A：我是 XX 主持人 A。
B：我是 XX 主持人 B。
A：……，这是《XX 开幕式》现场，欢迎广大海内外朋友的到来！
B：{活动举办地的文化 / 战略定位一句}
C：{本次活动的意义一句}
```

## 2. 串场三明治（每个节目必用）

```
① 回评上一节目（一句感受，要具体，不要"非常精彩"）
② 过渡：从节目内容引出人物 / 话题 / 情绪（1–2 句）
③ 报幕：节目名《》+ 必要的期待语
```

示例骨架：

```
A：谢谢！{对上一个节目的具体评价}。
B：{由此引出的话题或设问}……
A：接下来{铺垫}——
合：《节目名》！
```

- 回评要落到**具体细节**（某个画面、某个动作、某句话），空泛的赞美一律删。
- 报幕常用"接下来 / 下面这个节目 / 掌声有请"三种开口，避免全篇重复。

## 3. 双人互动（抖包袱）

两人一问一答制造轻松段落，模板：

```
A：{抛出一个小观察或自嘲}
B：怎么说？
A：{反转}
B：{接梗 / 吐槽}
A：{拉回主题}——合：{口号}
```

分寸：政务、追思、庄重场合不用；节庆、联欢、婚礼可用，且梗不指向具体人的隐私、外貌、年龄。

## 4. 变体：请嘉宾 / 特殊人物报幕

大型晚会常用，既减主持人负担又增强真实感。模板：

```
A：接下来要为大家报幕的是{人物身份}，欢迎{称呼}！
{人物}：大家好，我是{自我介绍}。
A：{围绕其身份的 2–3 句对话 / 追问}
{人物}：{其核心故事或金句}
A：那接下来就让我们跟随{线索}——
合：《节目名》！
```

## 5. 政务名单宣读法（三层分批）

真实政务稿绝不一次性念完所有名字，而是分三层，重要人物逐一念、其余打包：

```
A：请允许我隆重介绍出席活动的嘉宾和领导。首先介绍出席今天活动的重要外宾：……
   {逐一：职务 + 姓名全称 + 称谓（阁下 / 先生 / 女士）}
   以及来自{国家列表}的各位使领馆官员。欢迎你们！
B：出席今天开幕式的领导和国内重要嘉宾有：
   {逐一：单位职务 + 姓名，严格按主办方给的排序}
   ……；大家欢迎！
A：出席今天开幕式的领导和嘉宾还有：
   {地方主要领导 1–2 位}
   以及{机构类别 + 群体类别打包}的朋友。
   让我们以热烈掌声一并欢迎各位领导嘉宾的到来！
```

规则：
- **排序、职务、称谓一律照抄主办方名单**，一个字不改，不优化、不补全省份。
- 外宾称谓按外交惯例（大使"阁下"、副部长"先生"），拿不准就留占位提示。
- 打包项用"以及……的朋友"收尾，避免名单无限拉长。

## 6. 嘉宾内容不可预知时的接话（关键技巧）

致辞、传讲、访谈的内容往往事先拿不到全文。此时写**通用承接 + 概括性复述**，绝不假设其具体发言内容：

```
【XX 传讲结束后，主持人 A、B 上台】
A：谢谢{称呼}的分享。{对其身份 / 领域的一句概括性承接，不引用其未提供的具体语句}……
B：{由此引出下一个节目的过渡}
```

宁可写得"安全 + 通用"，也不要替嘉宾编造他说过的话。

## 7. 商业口播段（赞助 / 抽奖）

口播集中在节目间隙整段处理，不插进串场中间。模板：

```
A：{品牌名}{祝福语}。{品牌名}开启第 X 轮抽奖，{下载/打开 XX App，进入 XX 专区}，本轮将送出 X 万份{奖品}。
B：{第二个品牌}……
C：{第三个品牌}……
A：接下来的节目不仅精彩而且惊喜，请看《XX》。
```

要点：品牌名、奖品、份数、活动机制**全部由用户提供**，不得编造；抽奖引导语（App、专区名）必须逐字准确。

## 8. 分会场 / 外景连线

```
A：朋友们，跟随着{意象}，一起走进{地点}！
（XX 分会场）合：欢迎来到——{地名}！
{分会场主持人}：{当地一句特色描述}
{另一人}：{一句}
合：{四字口号 / 祝福}
```

连线要点：主持人点名 → 分会场自报地名 → 两句风物描写 → 合诵口号 → 切回主舞台。

## 9. 零点倒计时（跨年类）

```
A：亲爱的朋友们，让我们一起倒计时！
合：十！九！八！七！六！五！四！三！二！一！
A：过年啦！
（XX 分会场）合：{当地拜年语}
（YY 分会场）合：{当地拜年语}
```

倒计时前必有 2–4 句升华，倒计时后各分会场依次喊拜年，最后主会场收。

## 10. 结束语

**节庆晚会**：每人一句"去 XX 吧"式排比 → 主题升华 → 明确宣告结束 → 合：再见。

```
A：亲爱的朋友们，又到了{压轴曲名}的时候了。
B：{一句}
C：{一句}
A：{升华句}
合：{收束口号}
A：{主办方}{年份}{活动名}到这里，要跟大家说声再见了，再次祝福大家……
合：再见！
```

**政务 / 开幕式**：每人一句邀请语（诚邀您来 XX）→ 战略/文化升华 → 祝愿 → 宣告结束 → 合：朋友们，再见！

政治性升华句（涉领导人论述、会议精神、文件表述）**必须原样引用主办方提供的口径**，模型不自行生成。

## 11. 语言技法清单

- **短句优先**：播读词的句子多在 10–25 字，长句拆开。
- **排比 / 对仗**：`迎接……，迎接……，迎接……`；`于国家而言……，于个人而言……`。
- **具体代替抽象**：写"群鹤绕宫，鸣声彻天"而不是"场面盛大"。
- **重复关键词形成记忆点**：把核心动词/名词重复 3–4 次（如"动起来"）。
- **设问自答**：`你会用什么词？——我会选"和合"。` 一问一答带出主题。
- **数据必须有出处**：`全球已有超过 300 万海外弟子` 这类数字一律来自用户提供的资料。
- **口语连接词**：诶、那当然了、说得太对了、接下来、其实——用于双人互动段，单人抒情段不用。

## 12. 节奏与时长

- 单个串场 100–300 字，超过就砍。
- 全场每 3–5 个节目安排一次口播或连线，避免连续串场疲劳。
- 出稿后按 220 字/分钟核算总时长，与预计时长偏差超过 20% 就要调整。
